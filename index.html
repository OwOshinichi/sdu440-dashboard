เข้าสู่ระบบไม่ได้ใช่ไหม? ดูสาเหตุที่พบบ่อย
  • สมัครผ่าน Google: ต้องกดปุ่ม "Continue with Google" ด้านบน จะกรอกอีเมล/รหัสผ่านแทนไม่ได้ เพราะไม่มีรหัสผ่านผูกไว้
  • เพิ่งสมัครสมาชิก: ต้องรอ Admin ขององค์กรกด "อนุมัติ" ก่อน ถึงจะเข้าใช้งานได้
  • เคยถูกลบ/ปฏิเสธออกจากองค์กร: ลองล็อกอินอีกครั้งด้วยอีเมลเดิม ระบบจะส่งคำขอเข้าร่วมใหม่ให้ Admin อนุมัติอัตโนมัติ ไม่ต้องสมัครใหม่
  • ลืมรหัสผ่าน: กดลิงก์ "ลืมรหัสผ่าน?" เหนือปุ่มเข้าสู่ระบบ
  • สมัครแล้วแต่ Admin หาไม่เจอ: อาจพิมพ์ชื่อบริษัทตอนสมัครเพี้ยนไปจากที่มีอยู่ ทำให้ระบบสร้างบริษัทใหม่ให้โดยไม่ตั้งใจ ลองติดต่อ Admin เพื่อตรวจสอบชื่อบริษัทที่ใช้อยู่
